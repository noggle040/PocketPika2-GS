POCKET PIKA GS v0.6 — EASY CONTROLS

Only one file changed: PocketPikaView.swift

Upload this file DIRECTLY into the existing PocketPika/ folder in:
https://github.com/noggle040/PocketPika2-GS/tree/main/PocketPika

The file should replace PocketPika/PocketPikaView.swift (not create a new subfolder).

Controls:
LEFT/RIGHT: always change screens (Pika, Steps, Gift, Cards, Friend).
UP/DOWN: change animations, step views, gift amount, or card-game choice.
A: confirm/select (or pat on Pikachu).
B: back to Pikachu. Banks card-game winnings before leaving.
START: open Settings.
SELECT: open Steps.

Other changes:
- D-pad uses four separate 41-point nonoverlapping touch zones.
- A/B/START/SELECT have larger transparent hit targets and feedback.
- Card game A now submits your higher/lower selection; arrows don't risk Watts.
- Step sync refreshes approximately every 60 seconds while the app is active.
- Source retains the v0.5.2 step import and existing save data.
- Visible handheld version text: EASY v0.6.

Swift source has been syntax parsed locally; final compilation and behavior must be tested by GitHub Actions and on the Duo.
